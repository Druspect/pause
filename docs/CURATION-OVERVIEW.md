# Curated Collection Overview

Pause currently presents **36 verified public records** from **21 named stewards**. The earliest documented original era in the shelf is **1950**. These counts are generated from the published catalog and will change as reviewed records are added or withdrawn.

| Curation lens | Records | What the shelf preserves |
|---|---:|---|
| Operating systems | 11 | System source, release context, kernel design, and operating-system documentation. |
| Computer architecture | 7 | Hardware, machine interfaces, and distributed-system architecture papers. |
| Networks | 7 | Foundational protocol specifications for transport, mail, file transfer, naming, and the Web. |
| Databases | 4 | Relational and distributed-storage design records. |
| Source code | 3 | Direct code releases and preservation sources. |
| Programming languages | 2 | Language-design context and foundational texts. |
| Graphics, manuals | 2 | Specialized technical records that retain source-level evidence. |

The shelf deliberately mixes **archives, source code, documentation, papers, books, and software**. This is not a reading list of secondhand explanations. It is a map to original technical evidence, with a compact note on why each source still repays attention.

## Curation method

An entry becomes public only after the reviewer can identify a canonical source, primary publisher, original project, or documented preservation steward. The record must name a technical scope, provide a credible era where available, explain a concrete lasting value, and flag access or rights limitations. A source does not qualify merely because it is old, famous, or easy to link.

This makes Pause an **index to evidence**, not a duplicate file warehouse. The catalog points outward to the organizations and communities that actually steward the material.
