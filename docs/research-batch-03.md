# Pause Deep Research Batch 03: Inline Verification Notes

## RFC 791: Internet Protocol

The IETF Datatracker hosts the original September 1981 DARPA Internet Program protocol specification. The document limits IP to delivering an internet datagram from source to destination across interconnected networks and explicitly leaves end-to-end reliability, flow control, and sequencing to host-to-host protocols. It is a primary architecture record for datagram delivery and network-layer scope. Canonical source: <https://datatracker.ietf.org/doc/html/rfc791>.

## RFC 768: User Datagram Protocol

The IETF Datatracker hosts J. Postel’s 28 August 1980 UDP specification. It defines a transaction-oriented, connectionless datagram service with minimal protocol mechanism and does not guarantee delivery or duplicate protection. Its fields, user interface, and IP relationship make it a useful primary record for transport-layer trade-offs. Canonical source: <https://datatracker.ietf.org/doc/html/rfc768>.

## RFC 821: Simple Mail Transfer Protocol

The IETF Datatracker hosts Jonathan B. Postel’s August 1982 SMTP specification. The primary document covers message transfer among hosts, command and reply conventions, and the protocol’s approach to mail-relay interoperability. The Datatracker identifies it as a legacy Internet Standard that is obsolete, which makes it appropriate as historical architecture documentation rather than current operational guidance. Canonical source: <https://datatracker.ietf.org/doc/html/rfc821>.

## RFC 959: File Transfer Protocol

The IETF Datatracker hosts the October 1985 FTP specification by J. Postel and J. Reynolds. The document describes FTP’s historical evolution, the TCP transition, its user and server model, transfer functions, and optional commands. It is a primary record for early remote-file and storage-capability design, with legacy status clearly noted by the steward. Canonical source: <https://datatracker.ietf.org/doc/html/rfc959>.

## A Relational Model of Data for Large Shared Data Banks

IBM Research hosts E. F. Codd’s primary 1970 CACM publication record and links to the DOI. The abstract identifies the model’s concern with insulating users and applications from representation changes, introduces n-ary relations and a universal data sublanguage, and discusses redundancy and consistency. It is a verified primary database-architecture record. Canonical source: <https://research.ibm.com/publications/a-relational-model-of-data-for-large-shared-data-banks>.

## The Development of the C Language

Nokia Bell Labs hosts Dennis M. Ritchie’s electronic reprint of his 1993 paper. The author traces C’s influences and development from 1969 through 1973 alongside early Unix, later portability work, and standardization. It is a primary author record that preserves the historical reasoning behind a systems language that remains technically important. Canonical source: <https://www.nokia.com/bell-labs/about/dennis-m-ritchie/chist.html>.

## Chord: A Scalable Peer-to-peer Lookup Protocol for Internet Applications

MIT CSAIL hosts the primary paper by Ion Stoica and collaborators. The paper presents a distributed lookup protocol for peer-to-peer applications, with logarithmic lookup and routing behavior under dynamic node joins and departures. The paper is a primary architecture record for structured decentralized lookup systems. Canonical source: <https://pdos.csail.mit.edu/papers/ton:chord/paper-ton.pdf>.

## GNU Software Archive

The GNU Project’s official FTP directory is a durable public archive with program directories, release artifacts, manuals, mailing-list archives, bulletins, licensing material, and historic file timestamps. It offers a canonical release trail for foundational free-software tools and projects, rather than a third-party mirror or summary. Canonical source: <https://ftp.gnu.org/gnu/>.

## RFC 2616: Hypertext Transfer Protocol, HTTP/1.1

The IETF Datatracker hosts the June 1999 HTTP/1.1 specification. It presents HTTP as a stateless application protocol for distributed, collaborative hypermedia systems and documents the request methods, error codes, headers, and negotiation model of a key Web-era protocol. The Datatracker also makes its obsolete status explicit, preserving historical context. Canonical source: <https://datatracker.ietf.org/doc/html/rfc2616>.

## The Intel 4004

Intel’s Virtual Vault provides an institutional history record for the 1971 4004. It describes the Busicom project, the move from a custom twelve-chip calculator design to a programmable four-chip system, and the 4004’s role as Intel’s first microprocessor. This verifies historical scope and original era, but the catalog entry will be framed as a hardware-history record rather than a manual because the accessible primary page is an institutional history article. Canonical source: <https://www.intel.com/content/www/us/en/history/virtual-vault/articles/the-intel-4004.html>.

## Berkeley CSRG Archive CD-ROMs

UC Berkeley’s EECS archive page documents the Computer Systems Research Group source archive and lists 4.4BSD-Lite2 among its final Berkeley releases. It identifies the material as software developed by Berkeley and contributors, but it also requires an applicable Ancient Unix or Unix source license to obtain or use the archive. The record is appropriate for Pause with a prominent access restriction. Canonical source: <https://ftp.eecs.berkeley.edu/4bsd/csrg-cdrom.html>.
