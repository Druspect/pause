# Research Batch 02 Notes

## Xerox Alto Source Code

The Computer History Museum makes available, with Palo Alto Research Center permission, snapshots of Xerox Alto source code, executables, documentation, font files, and related files from 1975 through 1987. The material is organized by original PARC server and is available in viewable and original formats. CHM specifies non-commercial use. Canonical source: <https://computerhistory.org/blog/xerox-alto-source-code/>.

## RFC 793: Transmission Control Protocol

The IETF Datatracker identifies RFC 793 as the September 1981 Internet Standard, authored by Jon Postel and now obsoleted by RFC 9293. The original specification describes TCP as a highly reliable host-to-host protocol for packet-switched and interconnected networks, including layering, connection establishment, event processing, and interfaces. Canonical source: <https://datatracker.ietf.org/doc/rfc793/>.

## RFC 1034: Domain Names, Concepts and Facilities

The IETF Datatracker identifies RFC 1034 as the November 1987 Internet Standard by Paul Mockapetris, part of STD 13. It specifies DNS concepts and facilities, including a hierarchical name space, resource records, authoritative zones, name servers, resolvers, caching, referral, and refresh behavior. Canonical source: <https://datatracker.ietf.org/doc/rfc1034/>.

## Plan 9 from Bell Labs

The 9p.io Plan 9 site provides the fourth-edition overview, documentation, papers, manual pages, historical distribution images, source browsing, and history links for Plan 9 from Bell Labs. Canonical source: <https://9p.io/plan9/>.

## Project Mach

Carnegie Mellon University describes Project Mach as an operating-systems research project of the School of Computer Science from 1985 to 1994. Its public record links to Mach publications, manuals, tutorials, installation references, and code distributed by the project. Canonical source: <https://www.cs.cmu.edu/afs/cs/project/mach/public/www/mach.html>.

## The Google File System

Google’s 2003 paper describes GFS as a scalable distributed file system for data-intensive applications, designed for fault tolerance on commodity hardware and high aggregate client performance. The architecture uses a single master, multiple chunkservers, and clients that read or write chunk data directly after a metadata lookup. Canonical paper: <http://research.google.com/archive/gfs-sosp2003.pdf>.

## MapReduce

Google Research lists the 2004 OSDI paper by Jeffrey Dean and Sanjay Ghemawat. It describes a programming model and implementation for large data sets, with map and reduce functions; the runtime handles input partitioning, scheduling, machine failures, and inter-machine communication on commodity clusters. Canonical source: <https://research.google/pubs/mapreduce-simplified-data-processing-on-large-clusters/>.

## Bigtable

Google Research lists the 2006 OSDI paper describing Bigtable, a distributed structured-data store designed to scale to petabytes across thousands of commodity servers. The paper documents its data model, implementation, and flexible client control over data layout and format. Canonical source: <https://research.google/pubs/bigtable-a-distributed-storage-system-for-structured-data/>.

## System R

IBM Research lists the 1976 paper “System R: Relational approach to database management” in ACM Transactions on Database Systems. It is a primary IBM record for a foundational relational-database-system architecture reference. Canonical source: <https://research.ibm.com/publications/system-r-relational-approach-to-database-management>.

## Dynamo

Amazon’s 2007 SOSP paper presents Dynamo as a highly available key-value store used by Amazon core services. It documents trade-offs that prioritize availability under failure scenarios, including object versioning, application-assisted conflict resolution, consistent hashing, replica coordination, gossip membership, and decentralization. Canonical paper: <https://www.allthingsdistributed.com/files/amazon-dynamo-sosp2007.pdf>.
